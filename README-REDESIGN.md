# إعادة تصميم موقع ركن القائد

## التقنية الحالية
المشروع موقع ثابت مبني باستخدام HTML وCSS وJavaScript. تم الحفاظ على التقنية نفسها، مع إزالة الاعتماد غير الضروري على مكونات JavaScript الثقيلة في الصفحات الأساسية.

## أهم التحسينات
- اعتماد هوية وشعار ركن القائد في جميع الصفحات في جميع الصفحات.
- إنشاء شعار PNG/WebP بخلفية شفافة مع Favicons محسنة.
- تصميم RTL عربي حديث ومتجاوب بنظام Mobile First.
- إصلاح الروابط الحكومية التي كانت تحتوي على `https://https://`.
- إصلاح تكرار وسوم `body` و`main` وأخطاء HTML القديمة.
- إعادة بناء الهيدر والقائمة المحمولة والتذييل.
- تحسين بنية العناوين، الوصف، Open Graph، والبيانات الدلالية للـSEO.
- تحسين الوصول: روابط تخطي، تسميات حقول، Focus states، تنقل لوحة المفاتيح، ونصوص بديلة.
- تحسين الأداء: تقليل المكتبات المستخدمة، صور WebP للشعار، lazy loading، وJavaScript خفيف.
- الحفاظ على نموذج Web3Forms وبيانات التواصل وروابط ملفات PDF.

## التشغيل
لا يحتاج المشروع إلى تثبيت حزم. شغّله بخادم محلي:

```bash
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## الاختبار
راجع الصفحات على عرض 320 و375 و480 و768 و1024 و1366 و1440 و1920 بكسل. النموذج يحتاج اتصالًا بالإنترنت لإرسال البيانات إلى Web3Forms.
